# 말로 만든 3D 교구

AI에게 말로 부탁해 블렌더로 만든 3D 모형을 휴대폰·태블릿에서 손가락으로 돌려 보는 페이지입니다. AIEP 교내 연수 자료로 만들었습니다.

- 페이지: https://wolf0318.github.io/3d-gyogu/
- 모형: 눈사람과 나무, 직육면체 전개도(접혔다 펼쳐지는 움직임), 지구와 달(크기 비교, 실제 거리)

## 만든 도구

- 블렌더 5.3, 블렌더 재단 공식 MCP(Blender Lab), Claude
- 3D 보기: [model-viewer](https://modelviewer.dev/)
- 글꼴: Pretendard
